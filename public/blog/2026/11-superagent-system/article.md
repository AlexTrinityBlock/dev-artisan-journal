This file is the agent-readable source note for the article at `/blog/2026/11-superagent-system/`.

## English description

`dsh-superagent` is a proactive coding agent for one GitHub repository, packaged as a bundle for DeepSeek Harness. It listens to GitHub and, optionally, Feishu. When an authorized person asks for work, it opens a work item, works on it in its own agent session and directory, and answers in the original conversation, for example with a pull request.

Source: [deepseek-ai/dsh-superagent-prototype](https://github.com/deepseek-ai/dsh-superagent-prototype)
