## ⚡ Local Development

This repository strictly uses **Bun** as its package manager and execution runtime.

```bash
# Clone the repository
git clone https://github.com/AlexTrinityBlock/dev-artisan-journal.git
cd dev-artisan-journal

# Install dependencies with Bun
bun install

# Start local development server
bun x astro dev --background

# Build production bundle
bun run build

# Preview production build
bun run preview
```
